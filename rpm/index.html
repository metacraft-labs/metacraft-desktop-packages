Welcome to the Metacraft Labs RPM repository

One RPM repository for every Metacraft Labs product, such as CodeTracer and Reprobuild. It is signed with the organisation's package-repository key, 22F8 0A4A 65B0 8E36 AEA8 9F57 E127 BF3A C4CE 1719.

The simplest way to use it is a product's installer, which registers this repository and verifies the key for you:

curl -fsSL https://get.codetracer.com/sh | sh

To register it by hand, install the key (its SHA-256 is aa89db2215ce0b33e029b8302d4d94fac742b92d279f178437abe10d9b54c988):

root # curl -fsSL -o /usr/share/keyrings/metacraft-labs-archive-keyring.asc https://rpm.metacraft-labs.com/keys/metacraft-labs-archive-keyring.asc
root # rpm --import /usr/share/keyrings/metacraft-labs-archive-keyring.asc

then write /etc/yum.repos.d/metacraft-labs.repo:

[metacraft-labs]
name=Metacraft Labs
baseurl=https://rpm.metacraft-labs.com
enabled=1
gpgcheck=1
repo_gpgcheck=1
gpgkey=file:///usr/share/keyrings/metacraft-labs-archive-keyring.asc

rpm.codetracer.com redirects here, but a metacraft-rpms.repo that names it with the old CodeTracer key must be replaced by the one above.

Packages include:

  • codetracer - CodeTracer, a user-friendly time-travelling debugger for a wide range of programming languages
  • reprobuild - Reprobuild, a reproducible build system
